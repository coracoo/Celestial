# Celestial Heroes

3D 柏青哥 × 水浒娘化武将卡牌 × 三卡连携。一颗弹珠，一百零八将。

## 这是什么

一款把 **弹珠台** 和 **卡牌养成** 混在一起的网页游戏：

- **3D 柏青哥弹珠台** — 真实物理引擎驱动的钉阵、挡板与槽口，弹珠会反弹、会连锁、会掉进槽里
- **108 将娘化卡牌** — 水浒人物改编，每张卡有独立立绘、五行属性与武器技能
- **三卡 Build × 技能连携** — 出战三人，技能条件满足时自动触发连携
- **十二关战役** — 渭州到梁山，每关换钉阵布局、重力与 Boss 阶段
- **剧情模式** — 十二章原创幻想改编，战前战后都有对白

## 玩法

**目标** — 在击射预算用尽前击败 Boss。

**发射** — 移动鼠标瞄准，按住左键或 Space 蓄力，松开发射。

**瞄准** — 中央的「破绽」槽是敌人的弱点，瞄准它才有伤害。瞄准时会出现虚线预测反弹路径。

**救球** — 弹珠慢下来出现**金环**后可以开始救球蓄力，时间不等人。

**起手三人** — 按住 `1 / 2 / 3` 预览武器范围，移动鼠标旋转，松开施放。每球最多提供 3 秒慢放。

**连携** — 三张卡的技能条件满足时自动触发，可以在「盘面 / 连携」面板查看条件并锁定或解锁组合。

**抽卡** — 新玩家从武松、林冲、鲁智深开始，其余角色靠抽卡收集。抽卡用于收集与养成，不影响战斗平衡。

完整操作说明见游戏内的新手引导。

## 运行

需要 Node.js 22.12+。Windows 下用 `npm.cmd`。

```powershell
npm.cmd install
npm.cmd run dev
```

开发服务器在 http://127.0.0.1:5173

### 构建与预览

```powershell
npm.cmd run build
npm.cmd run preview
```

### 测试

```powershell
npm.cmd test
```

## 上游项目

本项目使用了以下开源项目的技术方案与素材产线：

| 项目 | 用途 |
|------|------|
| [Three.js](https://threejs.org/) | 3D 渲染与卡牌全息展示 |
| [Rapier](https://rapier.rs/) | 2D 物理引擎，驱动弹珠台钉阵 |
| [Vite](https://vite.dev/) | 构建工具与开发服务器 |
| [RuiC-card-skill](https://github.com/) | 卡牌的真实 Blender 导出几何与分层素材产线 |

角色设定与形象改编自《水浒传》，属于公有领域原著。

## 素材产线

卡牌的原始美术保存在 `立绘/`，经脚本处理后生成游戏加载的分层纹理：

```powershell
python -X utf8 scripts/prepare_cards.py
```

生成结果在 `public/art/`，已包含在仓库中。
